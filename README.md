# The Best Meal You Ever Had

One sentence about the best meal ever had: instant noodles at 2 a.m. on a
cold train platform, eaten standing up, with a stranger who shared his egg.
Cheap, cold, shared — and unforgettable.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the entry (1–200 characters, one line, not only
whitespace) and writes it plus a trailing newline to `/output/entry.txt`.
